# ChronoLite
⏱️ Stopwatch Web Application
A simple, interactive, and user-friendly stopwatch web app built using HTML, CSS, and JavaScript. This application allows users to start, pause, reset, and track lap times, making it perfect for timing workouts, tasks, or any activity that requires precise time tracking.

🚀 Features
✅ Start / Pause Stopwatch

🔁 Reset Timer to Zero

🕒 Track & Display Lap Times

🎯 Accurate Time Measurement

💻 Responsive & Clean UI

🛠️ Built With
HTML5 – Structure and layout

CSS3 – Styling and responsiveness

JavaScript – Core stopwatch logic and interactivity
